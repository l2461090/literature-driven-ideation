# Literature-driven-ideation｜文献驱动选题

输入一个科研主题，先获得 **重要文献、中文摘要与精读重点**，再形成 **3–5 个有文献依据、候选创新点和初步实验方案的课题方向**。

适用于个人研究者与课题组，不默认限定学历、年级或职业阶段。以实际经验、仪器、材料、平台与时间评估可行性。

## 它能帮你做什么？

- **检索与核验**：拆解研究主题，开展多路线文献检索，核对文献身份并保留来源链接。
- **先读文献**：列出重要文献，每篇附中文摘要、精读优先级、阅读重点及实际阅读层级。
- **分析已有工作**：区分论文结论、跨文献推断与待检验假设，对照最相近工作判断候选增量。
- **形成研究方案**：输出 3–5 个课题方向，包括文献依据、候选创新点、关键对照、初步实验和继续或退出条件。

中文摘要默认是忠于来源的概述，不是逐字复制原文。

## 推荐搭配：用 Codex 做文献调研

推荐将本 skill 与 **Codex** 搭配使用，把研究方向、关注问题与资源条件，变成有来源、可核验的文献导读与课题方案。

- **按方向精准筛选**：围绕你指定的研究主题检索，结合摘要与可获取正文判断相关性，而不只是匹配标题关键词。
- **真实来源，逐篇核验**：核对标题、作者、年份、DOI 或稳定标识，保留出版社页面或合法全文入口；区分已读摘要、正文与补充材料，方便回到原文复核。
- **文献先行，选题有据**：先看重要文献、中文摘要和精读重点，再讨论问题缺口、创新点与实验方案，减少脱离已有研究的空泛构想。
- **可选持续跟踪，减少重复劳动**：明确提出定时需求后，可配合 Codex 所在宿主支持的定时任务，周期性补充文献并更新分析；本 skill 不会自行创建定时任务。

这里推荐的是“检索 + 核验 + 分析 + 选题”的工作方式，并非承诺 AI 永不出错或绝不遗漏。官网受限、日期不明或摘要缺失时，应明确标注，不把未经核验的候选当成确定证据。定时任务的运行条件见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/automations)。

## 安装与调用

将压缩包中的 `literature-driven-ideation` 文件夹放入 Codex 可识别的 skills 目录。例如，按当前 [OpenAI 本地 skills 说明](https://learn.chatgpt.com/docs/build-skills)，可使用用户目录 `~/.agents/skills/`。

```bash
mkdir -p ~/.agents/skills
unzip literature-driven-ideation.zip -d ~/.agents/skills
```

然后在 Codex 中输入：

```text
使用 $literature-driven-ideation，围绕“微流控与超分子金属笼结合”开展文献驱动选题。
先按 Nature 引用格式列出重要文献，逐篇附中文摘要、精读标记和阅读重点，
再提出 3–5 个有文献依据、创新点及初步实验方案的课题方向。
```

也可以补充已有结果、可用仪器、材料、预算、期限、偏好应用、排除方向或年份范围。只提供主题时即可开始，不默认限定使用者人群。

## 默认交付

结果保存在当前工作目录的 `output/literature-driven-ideation/<日期>-<主题短名>/`；已有目录不覆盖。

| 文件 | 内容 |
|---|---|
| `topic-report.md` | 先给文献导读，再给综合分析与课题卡 |
| `literature-reading-guide.md` | Nature 格式引用、中文摘要、精读标记和阅读重点 |
| `evidence-matrix.md` | 文献证据、原文定位、阅读层级与限制 |
| `bibliography.csv` | 已核实书目及纳入状态 |
| `search-log.jsonl` | 真实检索轨迹及访问失败记录 |
| `references.bib` | 可靠书目信息可用时生成的 BibTeX |

## 证据边界

- 需要宿主提供可用的检索与来源读取工具；skill 本身不包含数据库订阅或付费全文权限。
- 无法取得正文或补充材料时明确标注，不把“推荐精读”写成“已经精读”。
- 候选创新点是检索范围内的研究建议，不保证全球首创、可发表或一定取得预期结果。
- 不自动安装依赖、购买数据库访问、修改 Zotero 或创建定时任务。
- 无法联网时仅分析用户提供的真实文献；没有任何文献时给检索计划，不编造文献依据。
